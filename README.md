# ПочваСвет — комплект для вайбкодинга Telegram-бота

Telegram-бот для фермеров и владельцев участков: по результатам экспресс-тестов почвы (кнопками
или по фото планшета на калибровочной карте) выдаёт сигнал светофора, дозы удобрений, сочетания
результатов, план по приоритетам, ведёт дневник поля и напоминает о сроках работ.

Этот репозиторий — стартовая точка разработки с ИИ-агентом: требования, проектные документы,
правила для агента, готовые промпты по этапам и работающий MVP.

## С чего начать

1. Прочитайте `docs/01_TZ.md` (что строим) и `docs/11_vibecoding_plan.md` (как строим по этапам).
2. Выполните этап 0 из плана: окружение, тестовый бот, проверка MVP.
3. Откройте репозиторий в Claude Code или Cursor — агент подхватит `CLAUDE.md` / `AGENTS.md` /
   `.cursor/rules/`. Вставьте промпт этапа 1 из плана.

```bash
python test_engine.py && python test_screens.py && python compare_engines.py

```

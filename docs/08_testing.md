# Тестирование и приёмка

## 1. Уровни тестов

| Уровень | Что | Как | Где |
| --- | --- | --- | --- |
| Ядро | `core/engine`, `units`, `reminders_plan`, `diff` | pytest + hypothesis; эталонные отчёты | `tests/core` |
| Правила | `rules.json` по схеме, ссылки уровней в сочетаниях, достижимость К1–К18 | pytest + jsonschema | `tests/core/test_rules.py` |
| Паритет | Python ↔ JS | `tools/compare_engines.py`, 5000 случайных входов | CI |
| Экраны | Все экраны: длина ≤ 4096, `callback_data` ≤ 64 байт, валидный HTML (только `b`, `i`, `code`), нет «висячих» кнопок | обход графа кнопок (см. `mvp/test_screens.py`) | `tests/screens` |
| Сервисы и БД | Репозитории, напоминания, тикеты | pytest-asyncio + PostgreSQL в Docker (service container в CI) | `tests/services` |
| Обработчики бота | Сценарии с фейковым Telegram | `Dispatcher.feed_update` с подменённой сессией бота (`aiogram` + свой `MockedSession`, записывающий исходящие запросы) | `tests/bot` |
| CV | Синтетические карты + реальный золотой набор | `tests/cv` (раздел 8 в `06_photo_recognition.md`) | `tests/cv` |
| LLM | Схема ответа, лимиты, шаблоны | Мок клиента; реальный набор 100 фото — вручную перед выпуском v3 | `tests/services/test_llm.py` |

Покрытие: `app/core` ≥ 90%, `app/screens` ≥ 80%, остальное — по сценариям.

## 2. Эталонные отчёты (golden files)

`tests/fixtures/golden/*.json` — 20 наборов ответов с проверенным агрономом отчётом
(`answers`, `month`, `expected_report`). Тест сравнивает отчёт целиком. Изменение правил, меняющее
эталон, требует обновить файл командой `pytest --update-golden` и подтверждения агронома в PR.

Обязательные наборы:

| № | Ситуация | Ожидаемые ключевые элементы |
| --- | --- | --- |
| G1 | Кислая супесь, картофель, P II, K II, N2 | 🔴; К1, К3, К4; план начинается с известкования |
| G2 | Перекормленный суглинок, зерновые, P V, K V, всё зелёное | 🟢; К12, К13; «не покупать»: известь, фосфор, калий |
| G3 | Шипение + pH 5,1–5,5 + картофель | нет строки извести; К14, К15 |
| G4 | Песок, картофель, K II | калий 🔴 |
| G5 | Навоз недавно + K V | К18, предупреждение |
| G6 | Апрель, органика 🟢, N2 | К8 |
| G7 | Июль, органика 🟢, N2 | нет К8 |
| G8 | Капуста, pH ≤ 5,0 | К16 🔴 |
| G9 | Зерновые, pH ≤ 4,5 | К17 🔴; доза извести по почве |
| G10 | Только площадь и культура, без тестов | итог «нет данных», предупреждение |
| G11–G20 | Случайные комбинации, отобранные агрономом | — |

## 4. Ручной чек-лист перед выпуском

- [ ] Все автотесты и `compare_engines` зелёные в CI
- [ ] Пройдены AT этапа в тестовом боте на Android и iOS
- [ ] Мини-приложение открывается из бота, светлая и тёмная тема читаются
- [ ] Длинный отчёт (все тесты красные) приходит без обрезки

- [ ] Агроном проверил 20 случайных отчётов
- [ ] Бэкап БД сделан и проверено восстановление на тестовой машине
- [ ] `meta.version` в `rules.json` увеличена, если правила менялись

## 1. Общие сведения

| Параметр | Значение |
| --- | --- |
| Название | Telegram-бот «ПочваСвет» (рабочее имя бота `@pochvasvet_bot`, уточняется) |
| Назначение | Помочь малому фермеру и владельцу приусадебного участка принять решение по известкованию и удобрениям на основе дешёвых экспресс-тестов почвы, без лаборатории |
| Пользователи | Фермеры (КФХ), владельцы ЛПХ и дачных участков в Беларуси; районные агрономы |
| Язык интерфейса | Русский (белорусский — после v2) |
| Платформа | Telegram Bot API + Telegram Mini App |
| Исходная точка | Работающий MVP в папке `mvp/`: мастер разбора результатов, брошюра, сочетания К1–К18, калькулятор, мини-приложение. Правила — `rules/rules.json` |

### 1.1. Цель

Фермер за 30–40 минут проводит тесты набора «ПочваСвет», фотографирует планшет на калибровочной карте
или вводит результаты кнопками и получает:

1. сигнал светофора по каждому показателю и по полю в целом;
2. конкретные действия: что внести, сколько (кг/га, г/м², кг на участок) и когда;
3. сочетания результатов, меняющие решение;
4. план по приоритетам при ограниченном бюджете;
5. дневник поля и напоминания о сроках работ.

### 1.2. Что не входит в систему

- Лабораторный анализ и микроэлементы; бот направляет такие случаи в лабораторию.
- Диагностика болезней и вредителей; при подозрении бот советует обратиться к агроному.
- Продажа удобрений и приём платежей (возможны в следующих версиях, вне этого ТЗ).
- Рекомендации для торфяных почв и земель с радиоактивным загрязнением сверх отсылки к агрохимическому паспорту.

## 2. Термины

| Термин | Значение |
| --- | --- |
| Тест | Одна реакция набора: pH, карбонаты, нитраты, фосфор, калий, органика (цвет, пена, черви), механический состав |
| Уровень | Результат теста из фиксированного списка (`ph1`…`ph6`, `p1`…`p6` и т. д.), см. `rules.json` |
| Сигнал | Цвет светофора: `green` — в норме, `yellow` — обрати внимание, `red` — действуй сейчас |
| Сочетание | Правило К1–К18, срабатывающее на комбинацию уровней, культуры и почвы |
| Разбор (анализ) | Набор ответов по одному полю на одну дату и рассчитанный по ним отчёт |
| Карта | Калибровочная карта А5 с метками ArUco, серой шкалой и зонами для планшета |
| Планшет | Прозрачный 6-луночный планшет из набора |
| Д. в. | Действующее вещество удобрения (N, P₂O₅, K₂O) |
| ЛПХ | Личное подсобное хозяйство |
| КФХ | Крестьянское (фермерское) хозяйство |

## 3. Роли

| Роль | Кто | Что может |
| --- | --- | --- |
| Фермер | Любой пользователь Telegram | Поля, разборы, фото тестов и растений, дневник, напоминания, калькулятор, паспорт поля, вопрос агроному |
| Агроном | Специалист районного управления или лаборатории, добавленный администратором | Получает «красные» и спорные случаи своего района, отвечает фермеру через бота, видит обезличенную статистику района |
| Администратор | Команда проекта | Управляет агрономами и районами, загружает новую версию правил и калибровки, смотрит метрики, выгружает данные |

Роль определяется по таблице `users.role`; по умолчанию `farmer`.

## 6. Ограничения Telegram, которые обязательно учитывать

- Длина сообщения — до 4096 символов, подпись к фото — до 1024; длинные отчёты делятся на несколько сообщений.
- `callback_data` — до 64 байт; схема кодирования — в `02_user_flows.md`.
- Bot API скачивает файлы до 20 МБ.
- Фото, отправленное «как фото», сжимается до ~1280 px по длинной стороне; для распознавания лучше «как файл». Бот принимает оба варианта.
- Не больше ~30 сообщений в секунду суммарно и ~1 в секунду в один чат; рассылки — через очередь.
- Мини-приложение открывается только по HTTPS.
- Бот не может первым написать пользователю, который его не запускал или заблокировал; ошибку блокировки обрабатывать и помечать пользователя неактивным.

## 9. Приёмка

Этап принимается, если:

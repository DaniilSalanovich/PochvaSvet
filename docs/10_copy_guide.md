# Тексты бота: правила

Читатель — фермер или дачник без агрономического образования, часто с телефоном в поле.
Текст должен сказать, **что делать**, за одно прочтение.

## 1. Голос

- На «вы», спокойно и по делу, как опытный агроном-сосед. Без восклицаний, без «Ура!» и «Отлично!».
- Сначала действие, потом объяснение: «Известкуйте этой осенью: на кислой почве удобрения работают вполсилы».
- Короткие предложения, до 20 слов. Один абзац — одна мысль.
- Глаголы в повелительном наклонении для действий: «внесите», «повторите тест», «заделайте».
- Неуверенность называем прямо: «по фото это предположение», «результат может быть завышен».
- Никогда не обещаем урожай и не пугаем: «урожай под угрозой» допустимо только для красного сигнала.

## 2. Светофор и эмодзи

- Эмодзи сигналов — только 🟢 🟡 🔴 и ⚪ (нет данных), всегда перед названием показателя.
- Навигационные значки на кнопках: 🏠 ⬅️ ➕ ✏️ 🗄 📒 📄 📷 🧪 🧮 ⏰ 👩‍🌾 📖 🔗 💾 ✅ ⏳ ✖️ ⏭ 🔁. Других не добавлять.
- В тексте сообщений эмодзи не используются как украшения.

## 3. Числа и единицы

| Правило | Пример |
| --- | --- |
| Десятичная запятая | 4,6; 0,5 га |
| Диапазон через короткое тире без пробелов | 3–4 т/га |
| Пробел между числом и единицей | 600 м², 12 кг |
| Тысячи — неразрывным пробелом | 1 450 кг |
| Единицы: т/га, кг/га, г/м², кг N/га, кг P₂O₅/га, кг K₂O/га, мг/кг, мг/л, сотки, га, м² | |
| Даты — ДД.ММ или ДД.ММ.ГГГГ | 15.09, 12.04.2026 |
| Приблизительно — «≈» | ≈ 210 кг |

## 4. Словарь

| Пишем | Не пишем |
| --- | --- |
| известковать, известь, доломитовая мука | раскислять, мелиорант |
| поле, участок | контур, элементарный участок |
| разбор результатов | анализ данных, инференс |
| удобрение, доза | агрохимикат, норма внесения (только в цитатах нормативов) |
| результат может быть неточным | low confidence, ошибка распознавания |
| кнопка, нажмите | тапните, кликните |
| агроном района | специалист РУСХП |
| группа обеспеченности (I–VI) | класс, категория |
| действующее вещество (д. в.) — при первом упоминании расшифровать | д.в. без пояснения |

## 5. Форматирование в Telegram

- `parse_mode=HTML`. Разрешены `<b>`, `<i>`, `<code>`. Жирным — заголовок сообщения и название показателя;
  курсивом — пояснение «почему» и дисклеймер.
- Списки — «• » для действий, «1.» для плана по порядку.
- Кнопки: до 30 символов, начинаются с глагола или существительного-раздела: «Новый разбор»,
  «Сохранить в дневник», «Спросить агронома».
- Одно сообщение — один экран; редактируем сообщение при навигации, а не шлём новое.

## 6. Шаблоны

| Ситуация | Текст |
| --- | --- |
| Ожидание | «Проверяю фото…» / «Готовлю рекомендации…» (через `answer_callback_query` или chat action) |
| Нет данных | «Полей пока нет. Добавьте первое — это займёт минуту.» |
| Ошибка ввода | «Не понял площадь. Напишите, например: 6 соток, 0,5 га или 600 м².» |
| Устаревшая кнопка | «Этот шаг устарел. Начните заново из меню.» |
| Ошибка сервера | «Что-то пошло не так, мы уже разбираемся. Попробуйте через минуту. Код: {error_id}» |
| Подтверждение удаления | «Удалить поле «{name}» вместе с дневником? Это нельзя отменить.» [Удалить] [Отмена] |
| После сохранения | «Сохранено в дневник поля «{name}».» |

## 7. Проверка текста перед выпуском

- [ ] Первое предложение говорит, что делать или что произошло
- [ ] Нет терминов из правой колонки словаря
- [ ] Числа по правилам раздела 3
- [ ] Сообщение читается без прокрутки на экране телефона (если это не отчёт)
- [ ] Для красного сигнала есть конкретное действие и срок

# Распознавание тестов по фото (v2)

Цель: по одному фото прозрачного планшета, лежащего на калибровочной карте, определить уровни pH,
нитратов, фосфора, калия и цвета органики с оценкой уверенности. Распознавание — классическое
компьютерное зрение (OpenCV), **без нейросетей и LLM**: результат должен быть воспроизводимым и объяснимым.

Числовые пороги ниже — стартовые; финальные значения подбираются на калибровке (раздел 7)
и хранятся в файле калибровки, а не в коде.

растр для обработки — 10 px/мм (1480 × 2100 px). Координаты — от левого верхнего угла, в мм.

| Зона планшета (контур 1 мм) | x 10,1–137,9; y 30,0–115,5 (стандартный 6-луночный планшет 127,8 × 85,5, альбомно) | Куда класть планшет |

## 2. Конвейер

```python
recognize(image: bytes, calibrations: CalibrationStore) -> RecognitionResult
```

| Шаг | Что делаем | Отказ (код проблемы) |
| --- | --- | --- |
| 1. Декодирование | `cv2.imdecode`; поворот по EXIF; уменьшение до 2400 px по длинной стороне | `bad_image` |
| 2. Метки | `cv2.aruco.ArucoDetector(DICT_4X4_50)`; нужны ≥ 3 из id 0–3; при трёх — четвёртый угол достраивается аффинно | `no_markers` |
| 3. Размер | Сторона метки ≥ 40 px | `too_small` (карта слишком далеко) |
| 4. Выравнивание | Гомография по 12–16 углам меток в канонический растр 1480 × 2100; ошибка репроекции ≤ 3 px | `perspective` (снято под сильным углом) |
| 5. QR | Чтение QR партии `cv2.QRCodeDetector`; не прочитан → партия по умолчанию | — (предупреждение в логах) |
| 6. Резкость | Дисперсия лапласиана по области серой шкалы ≥ 80 | `blur` |
| 7. Экспозиция | L* светлейшей серой плашки (до коррекции) в [70; 98]; доля пикселей с каналом = 255 в лунках ≤ 2% | `dark`, `overexposed` |
| 8. Цветокоррекция | Линеаризация sRGB; матрица 3 × 3 + смещение методом наименьших квадратов по 12 плашкам (серые + цветные) к эталонам партии; средний остаток ΔE2000 ≤ 6 | `color_cast` (только предупреждение, уверенность × 0,7) |
| 9. Блики | В каждой лунке доля пикселей с V > 0,95 и S < 0,1 | > 15% → тест `uncertain` с подсказкой про блик |
| 10. Область лунки | Круг радиусом 0,55 × радиус лунки; исключаем блики и 5% самых тёмных пикселей (пузыри, тени); медиана Lab | — |
| 11. Чтение тестов | По «читателю» на тест, раздел 3 | `not_found` для пустой лунки |
| 12. Сборка | `RecognitionResult` | — |

Время на 1 vCPU — ≤ 2 с. Конвейер запускается в `ProcessPoolExecutor` с таймаутом 15 с.

## 3. Читатели тестов

Все кривые и пороги — из файла калибровки партии (раздел 6).

### pH (A1)

- Признак: точка в пространстве Lab после коррекции.
- Калибровочная кривая: эталонные растворы pH 4,0–7,5 с шагом 0,25 → средние Lab.
- Значение: ближайший отрезок кривой по ΔE2000, линейная интерполяция pH внутри отрезка.
- Уровень: пороги 4,5 / 5,0 / 5,5 / 6,0 / 7,0 → `ph1`…`ph6`.
- Граница: |pH − порог| < 0,15 → `boundary`.
- Уверенность: `1 − d/15`, где d — ΔE до кривой, обрезка в [0; 1].
- Пустая лунка: C* < 8 и L* > 85 → `not_found`.

### Нитраты (A2 или полоска)

- Признак: a* (розовая составляющая) после коррекции; для полоски — медиана подушечки реакции в зоне полоски.
- Кривая: стандарты 0, 5, 10, 25, 50, 100 мг/л NO₃⁻ → a*, монотонная интерполяция.
- Пересчёт: мг/л × 5 × 0,226 = мг N-NO₃/кг; пороги 7 / 15 / 40 → `n1`…`n4`.
- Граница: ±15% от порога.

### Фосфор (A3 против контроля B3)

- Признак: Δb = b*(B3) − b*(A3) (синева уменьшает b*), с поправкой на L*.
- Пороги Δb для границ групп I/II, II/III, III/IV, IV/V, V/VI — из стандартов, приготовленных так,
  чтобы соответствовать 60, 100, 150, 250, 400 мг P₂O₅/кг при разведении набора.
- Выше последнего стандарта → `out_of_range`: бот просит повторить с разведением 1:20.
- Контроль B3 окрашен (Δb контроля к белому > порога) → реактив испорчен: тест `uncertain`,
  сообщение «Контрольная лунка посинела — реактив мог испортиться».

### Калий (B1)

- Признак: индекс мутности `T = 1 − Σ wᵢ·Cᵢ(лунка) / Σ wᵢ·Cᵢ(эталон)`, где Cᵢ — контраст Майкельсона
  полосы i по L*: `(Imax − Imin)/(Imax + Imin)`, веса wᵢ больше для тонких полос.
- Пороги T для групп I–VI — из стандартов KCl.
- Жёлтый оттенок мути не используется как основной признак (зависит от реактива), только для проверки,
  что реакция прошла (b* > порога), иначе `uncertain`.

### Цвет органики (B2)

- Признак: Lab почвенной пасты.
- Сравнение с 5 плашками гумусовой шкалы на этой же карте (после коррекции) по ΔE2000;
  плашка 1 → `c1`, 2 → `c2`, 3–5 → `c3`.
- Уверенность снижается, если ΔE до ближайшей плашки > 12 (необычный цвет: торф, глина, пересушено).

### Что не читается по фото

Карбонаты (шипение), пена, черви, механический состав — бот спрашивает кнопками (в v3 возможно фото
пробирки с пеной на линейке).

## 4. Статусы и что делает бот

| Статус | Условие | Поведение бота |
| --- | --- | --- |
| `ok` | уверенность ≥ 0,6 и не граница | Показывает уровень, кнопка «Изменить» |
| `boundary` | значение у порога | Показывает два соседних уровня, просит выбрать по цвету или повторить тест |
| `uncertain` | уверенность < 0,6, блик, цветовой сдвиг | Просит подтвердить кнопками уровней |
| `not_found` | лунка пустая | Спрашивает уровень кнопками или «не делал» |
| `out_of_range` | фосфор темнее шкалы | Инструкция по разведению, повторное фото |

## 5. Сообщения о качестве фото

| Код | Текст пользователю |
| --- | --- |
| `bad_image` | Не получилось открыть фото. Пришлите его ещё раз — лучше «как файл». |
| `no_markers` | Не вижу калибровочную карту. В кадре должны быть все четыре чёрно-белых квадрата по углам карты. |
| `too_small` | Карта слишком далеко. Держите телефон на высоте 25–35 см, чтобы карта заняла почти весь кадр. |
| `perspective` | Снято под углом. Держите телефон параллельно карте, прямо над ней. |
| `blur` | Фото размыто. Упритесь локтями в стол, коснитесь экрана, чтобы навести фокус, и снимите ещё раз. |
| `dark` | Слишком темно. Снимайте у окна днём, без вспышки. |
| `overexposed` | Пересвет или блики. Уйдите из-под прямого солнца или лампы, снимайте в рассеянном свете. |
| `glare` (в лунке) | В лунке {тест} блик — сдвиньте планшет или телефон чуть в сторону. |
| `color_cast` | Свет сильно окрашен (жёлтая лампа?). Результат может быть неточным — лучше переснять при дневном свете. |

Если фото пришло сжатым (длинная сторона < 1280 px) — подсказка: «Для точности отправьте фото как файл».

## 7. Калибровка и проверка точности

1. Химик готовит стандарты: буферы pH 4,0–7,5 (шаг 0,25), нитрат 0–100 мг/л, фосфат и калий на
   границах групп, плюс 100–150 реальных проб почвы с лабораторными значениями (pH KCl, P₂O₅ и K₂O
   по Кирсанову, N-NO₃).
2. Каждую лунку снимают 3 телефонами (разные производители) × 3 условия света (дневной у окна,
   пасмурно на улице, тёплая лампа) → не менее 300 размеченных фото.
3. `tools/calibrate.py` строит кривые и пороги по стандартам, проверяет на реальных пробах
   (кросс-валидация по пробам, не по фото) и пишет файл калибровки + отчёт.
4. Цели приёмки:

| Метрика | Цель |
| --- | --- |
| pH: точный уровень / ±1 уровень | ≥ 80% / ≥ 98% |
| Фосфор, калий: ±1 группа | ≥ 90% |
| Нитраты: точный уровень | ≥ 80% |
| Цвет органики: точный уровень | ≥ 75% |
| Доля фото, отклонённых по качеству, при соблюдении инструкции | ≤ 15% |
| Ложный `ok` при реально ошибочном уровне > 1 | ≤ 2% |

## 8. Синтетические тесты (обязательны для разработки без набора)

`tests/cv/synth.py` рисует карту по спецификации раздела 1 с заданными цветами лунок, затем применяет
перспективу (до 25°), поворот (0–360°), масштаб, гамму 0,8–1,2, цветовую температуру 3000–6500 K,
шум и JPEG-сжатие 60–95. Тесты проверяют:

- метки находятся, ошибка репроекции ≤ 3 px;
- после цветокоррекции ΔE лунки к заданному цвету ≤ 3;
- уровни, заданные цветами из тестовой калибровки, читаются правильно в ≥ 99% синтетических кадров;
- кадры без карты, размытые (Gaussian σ ≥ 4), тёмные и пересвеченные отклоняются с правильным кодом.

## 9. Данные и приватность

Фото сохраняются на диск только при `dataset_consent = true`; иначе хранится только `tg_file_id`
и числовые результаты. Метаданные EXIF (геолокация) удаляются перед сохранением.

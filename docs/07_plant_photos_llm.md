# Подсказки по фото растений (v3)

Фото листьев — вспомогательный канал: оно подсказывает, **какой тест сделать**, и подтверждает
результат теста. Диагнозов бот не ставит; доз по фото не даёт. Модель возвращает только значения
из закрытого списка; тексты для пользователя бот берёт из своих шаблонов, а не из ответа модели.

## 1. Сценарий

1. Пользователь: «📷 Фото растения» → выбирает поле (или «без поля») → присылает 1–3 фото.
2. Бот: «Смотрю…» → вызывает модель (таймаут 30 с).
3. Если модели не хватает данных — до 2 уточняющих вопросов кнопками
   (например: «Пожелтение на старых или молодых листьях?»).
4. Ответ по шаблону (раздел 4) + кнопки: «Сделать тест {X}» (запускает мастер на нужном шаге),
   «Спросить агронома», «В меню».

## 2. Вызов модели

- Клиент `app/services/llm.py`, провайдер и модель — из `LLM_PROVIDER`, `LLM_MODEL`, ключ — `LLM_API_KEY`.
- Изображения: уменьшить до 1568 px по длинной стороне, JPEG 85, EXIF удалить.
- Температура 0; ответ — строго JSON по схеме ниже (structured output / tool use, если провайдер
  поддерживает; иначе — парсинг с повтором 1 раз при ошибке).
- Лимиты: 10 фото на пользователя в сутки, 200 в сутки на весь бот (настраивается); при превышении —
  вежливый отказ и совет сделать тесты.
- В запрос не передаются имя пользователя, Telegram ID, координаты.

### Системный промпт

```text
Ты помогаешь агроному-консультанту по фото растений на полях и огородах Беларуси
(дерново-подзолистые почвы; культуры: зерновые, картофель, капуста, свёкла, морковь, лук).
Задача: описать видимые симптомы и указать вероятную причину ТОЛЬКО из списка.
Не ставь диагноз, не называй доз удобрений, не советуй пестициды.
Если фото не растение, нерезкое или симптомов не видно — так и скажи через поля ответа.
Если симптомы похожи на болезнь, вредителя, гербицид, засуху или переувлажнение — укажи это,
а не дефицит питания.
Отвечай только JSON по заданной схеме, на русском языке в текстовых полях.
```

Пользовательское сообщение: фото + контекст `{"crop": "potato", "month": 6, "last_tests": {"ph":"ph2","k":"k2"}}`
(последние тесты поля, если есть).

### Схема ответа

```json
{
  "type": "object",
  "required": ["is_plant", "image_ok", "symptoms", "probable_cause", "confidence", "questions"],
  "additionalProperties": false,
  "properties": {
    "is_plant": {"type": "boolean"},
    "image_ok": {"type": "boolean"},
    "crop_guess": {"enum": ["grain", "potato", "veg", "other", "unknown"]},
    "symptoms": {"type": "array", "maxItems": 5, "items": {"enum": [
      "uniform_yellowing_old_leaves", "purple_red_tint", "dark_dull_green", "leaf_edge_scorch_old",
      "interveinal_chlorosis_old", "interveinal_chlorosis_young", "growing_point_death",
      "spots_lesions", "wilting", "deformed_leaves", "insect_damage", "stunted_growth", "none_visible"]}},
    "probable_cause": {"enum": ["N", "P", "K", "Mg", "Fe_Mn", "B", "acidity", "disease_or_pest",
      "herbicide", "water_stress", "cold", "unclear"]},
    "confidence": {"enum": ["low", "medium", "high"]},
    "share_affected": {"enum": ["single_plants", "patches", "most_of_field", "unknown"]},
    "questions": {"type": "array", "maxItems": 2, "items": {"enum": [
      "which_leaves_old_or_young", "recent_cold_or_rain", "recent_herbicide", "recent_fertilizer"]}}
  }
}
```

## 3. Соответствие причин и тестов

| `probable_cause` | Какой тест предложить | Шаблон «что это может быть» |
| --- | --- | --- |
| `N` | Нитраты | Похоже на нехватку азота: равномерное пожелтение нижних листьев |
| `P` | pH + фосфор | Похоже на нехватку фосфора; на холодной почве весной такое бывает и при нормальном фосфоре |
| `K` | Калий | Похоже на нехватку калия: «ожог» краёв нижних листьев |
| `Mg` | pH (+ доломит при подтверждении) | Похоже на нехватку магния: пожелтение между жилками на старых листьях |
| `Fe_Mn` | pH, карбонаты | Похоже на нехватку железа или марганца, часто при избытке извести |
| `B` | — (лаборатория) | Похоже на нехватку бора; подтвердите в лаборатории |
| `acidity` | pH | Возможна сильная кислотность почвы |
| `disease_or_pest`, `herbicide` | — | Похоже не на питание, а на болезнь, вредителя или гербицид — покажите агроному |
| `water_stress`, `cold` | — | Вероятно, погодный стресс; подождите 5–7 дней и посмотрите снова |
| `unclear` | Полный набор тестов | По фото причину не определить — сделайте тесты почвы |

Сигнал: `single_plants` → жёлтый; `patches` → жёлтый; `most_of_field` + `wilting`/`stunted_growth` → красный
с советом сделать тест сегодня. При `confidence = low` всегда добавляется «по фото это предположение».

## 4. Шаблон ответа

```
🟡 Вероятная причина: нехватка калия
Что видно: «ожог» краёв нижних листьев, отдельные растения.
Что сделать: тест на калий из набора — займёт 20 минут.
По фото это предположение; точный ответ даст тест.
[🧪 Сделать тест на калий] [👩‍🌾 Спросить агронома] [🏠 Меню]
```

## 5. Проверка качества

Набор из 100 фото с ответами агронома (по 10–15 на причину + «нет симптомов» + «не растение»).
Цели: правильная причина или `unclear` — ≥ 80%; никогда не путать `disease_or_pest` с дефицитом
в > 10% случаев; 100% ответов проходят JSON-схему.

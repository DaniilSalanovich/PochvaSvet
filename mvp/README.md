# ПочваСвет — интерактивная брошюра в Telegram

Бот и мини-приложение, которые по результатам тестов почвы выдают сигнал светофора,
дозы удобрений, совпавшие сочетания (К1–К18), план по приоритетам и список того,
что не нужно покупать. Содержание полностью совпадает с брошюрой
«ПочваСвет: что делать по результатам тестов».

## Что внутри

| Файл | Назначение |
| --- | --- |
| `rules.json` | Единый источник правил: уровни каждого теста, дозы, сочетания К1–К18, календарь, удобрения. Правится агрономом без программиста |
| `engine.py` | Движок рекомендаций для бота (без зависимостей) |
| `screens.py` | Экраны бота: тексты и кнопки (без зависимостей от Telegram) |
| `bot.py` | Telegram-бот на aiogram 3 |
| `webapp/engine.js` | Тот же движок на JavaScript для мини-приложения |
| `webapp/template.html` | Мини-приложение: разбор, брошюра, сочетания, пересчёт |
| `build_webapp.py` | Собирает `webapp/index.html` (для Telegram) и `webapp/preview.html` |
| `test_engine.py`, `test_screens.py`, `compare_engines.py` | Проверки |

## Что умеет бот

- **/check — «Разобрать мои результаты».** 12 шагов: почва, культура, pH, карбонаты, нитраты,
  фосфор, калий, три признака органики, недавний навоз, площадь. На каждом шаге кнопки
  показывают цвет сигнала с учётом уже введённых ответов; любой тест можно пропустить.
  В конце — итог по полю, план по приоритетам, «не покупать», карточки по тестам с дозами
  в кг/га, г/м² и килограммах на участок, совпавшие сочетания с кнопками «Подробнее».
- **/brochure — брошюра.** Все уровни каждого теста: что значит, что делать, дозы,
  связанные сочетания; бюджет, календарь, безопасность.
- **Сочетания К1–К18** — список и карточка каждого: когда срабатывает, почему, что делать.
- **/calc — пересчёт дозы** в вес удобрения, граммы на м² и ложки.
- **Кнопка «Брошюра»** рядом с полем ввода открывает мини-приложение (если задан `WEBAPP_URL`).

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Разместите `webapp/index.html` на любом HTTPS-хостинге (GitHub Pages, Netlify,
   свой сервер) — Telegram открывает мини-приложения только по HTTPS.
3. Установите зависимости и запустите:

```bash
pip install -r requirements.txt
export BOT_TOKEN="123456:ABC..."
export WEBAPP_URL="https://ваш-сайт/index.html"   # можно не задавать
python bot.py
```

Бот работает в режиме long polling: достаточно любого сервера или компьютера с Python 3.10+.
Состояние мастера хранится в памяти процесса; для работы на нескольких серверах замените
хранилище aiogram на Redis.

## Как менять рекомендации

1. Отредактируйте `rules.json` (дозы, тексты, новые сочетания).
2. Запустите проверки и пересоберите мини-приложение:

```bash
python test_engine.py        # логика движка
python test_screens.py       # все экраны бота: кнопки, лимиты Telegram, HTML
python compare_engines.py    # бот и мини-приложение дают одинаковые ответы (нужен Node.js)
python build_webapp.py       # обновить webapp/index.html
```

3. Загрузите новый `webapp/index.html` на хостинг и перезапустите бота.

**Новое сочетание** добавляется в `combos`: условие `when` перечисляет допустимые уровни
(`"ph": ["ph1", "ph2"]`), а также `texture`, `crop`, `org` (итог органики: red/yellow/green),
`manure`, `month`; `any` — «хотя бы одно из», `all_green` — все показатели зелёные.
`light_rules` меняют цвет сигнала в зависимости от почвы или культуры.

Дозы — ориентиры для малых хозяйств на дерново-подзолистых почвах Беларуси; перед
массовым применением сверьте их с рекомендациями Института почвоведения и агрохимии НАН Беларуси.
